01 — Framework

Four Categories of AI Tools

Understanding what a tool is before deciding when to use it. Every tool on our list falls into one of four archetypes.

① General-Purpose AI Assistants

Tools: Google Gemini · OpenAI ChatGPT · Anthropic Claude
A conversational AI you talk to. Great for research, writing, analysis, summarisation, brainstorming, and code explanation. You bring the task; it brings broad knowledge. Works best when you are guiding the interaction step by step.

② Agentic Coding Tools — Terminal / CLI First

Tools: Google Antigravity · OpenAI Codex · Anthropic Claude Code · IBM Bob
AI agents that write, test, and refactor code across your full codebase. They read files, run shell commands, browse the web, and work end-to-end with minimal hand-holding. Live in your IDE, terminal, or both.

③ AI-Native IDEs — Code Editor + Agent Bundled

Tools: Cursor
A full code editor that replaces or extends VS Code, with deep agentic capability built into the editing surface. Inline diffs, multi-file context, cloud agents, and a model marketplace — all in one app.

④ Enterprise AI Platforms — Governed Workspaces

Tools: Microsoft Copilot · IBM ICA (IBM Consulting Advantage) · IBM ICA Edge
Productivity and delivery platforms tightly integrated with an organisation's existing tools, data, and governance. Not a raw model — a governed, role-specific experience that brings AI into the flow of real work at enterprise scale.

02 — Category 1

General-Purpose AI Assistants

Conversational AI you interact with through chat. Broad knowledge, multimodal in most cases, best when used interactively.

G

Google Gemini

Google DeepMind
AI Assistant

Google's flagship multimodal AI assistant — available as a web app, mobile app, and embedded into Google Workspace. Powered by the Gemini family of models (currently Gemini 3 Pro / Flash), it handles text, images, audio, and code in a single conversation. Originally launched as "Bard" in March 2023.

  • Deep integration with Google Workspace (Gmail, Docs, Sheets, Meet)
  • Multimodal: text, images, audio, video, and code
  • Deep Research mode for extended, cited research tasks
  • Gemini Live — real-time voice conversation with camera sharing
  • Canvas — collaborative writing and document creation surface
  • Gem-bots — customisable expert personas for recurring tasks
  • Extensions to YouTube, Maps, and Google services
Multimodal Google Workspace Consumer + Business Web / Mobile
⊙

OpenAI ChatGPT

OpenAI
AI Assistant

OpenAI's consumer and enterprise AI assistant — the tool that popularised conversational AI. Powers GPT-5 and o-series reasoning models. ChatGPT is the interface; the underlying API serves developers through the Responses API and Agents SDK with tools like web search, code interpreter, file search, and computer use.

  • Access to GPT-5 and o-series reasoning models
  • Built-in web search, code interpreter, image generation (DALL·E), and file analysis
  • Projects for persistent, organised multi-session work
  • Memory — remembers context across conversations
  • GPT-Live — real-time voice and screen sharing
  • ChatGPT Teams/Enterprise with privacy and admin controls
  • Strong developer API ecosystem (Responses API, Agents SDK, MCP support)
GPT-5 / o-series Reasoning Models Consumer + Enterprise API Ecosystem
A

Anthropic Claude

Anthropic
AI Assistant

Anthropic's general AI assistant — built around Constitutional AI for safety and helpfulness. Claude is specifically positioned as a problem solver and task executor. The latest "Cowork" feature (part of Claude Pro/Max) allows Claude to run multi-step tasks autonomously across your tools — reading transcripts, updating CRM records, building presentations.

  • Industry-leading long context window (up to 1M tokens on Claude Opus)
  • Strong reasoning, analysis, and document comprehension
  • Cowork mode — autonomous multi-step task execution across connected apps
  • Integrations: Google Drive, Salesforce, Slack, Gmail, Gong, BigQuery, Jira
  • Projects — persistent memory and context for ongoing work
  • Styles — consistent tone and voice for writing tasks
  • Safety-first design via Constitutional AI
Long Context Constitutional AI Cowork / Agentic Safety Focus
Key takeaway: These three tools are broadly interchangeable for general chat, writing, and research. The key differentiators are ecosystem (Gemini → Google Workspace; Copilot → Microsoft 365; ChatGPT → OpenAI API), reasoning depth (ChatGPT's o-series models lead for complex multi-step reasoning), and safety / trust (Claude leads on Constitutional AI and long-context fidelity).
03 — Category 2 & 3

Agentic Coding Tools & AI-Native IDEs

Tools that do more than suggest code — they autonomously read, write, test, and ship across your full codebase.

▲

Google Antigravity

Google
Dev Agent

Google's agentic coding platform — available as a desktop app (Antigravity 2.0), a CLI (agy), and IDE extensions for VS Code, JetBrains, Zed, and Xcode. Designed to be the "central command center" for AI agents that execute complex coding and knowledge work tasks. Acts as an independent agent manager, not dependent on a specific IDE.

  • Standalone desktop app (2.0) — manages multiple agents synchronously or asynchronously
  • Skills system — custom, reusable agent behaviours (similar to Bob's skills)
  • Browser automation via Chrome integration with allowlist/denylist controls
  • Terminal sandbox for safe code execution
  • MCP server integration and custom subagents
  • Projects — scoped workspace with isolated security policies
  • Artifacts — visual implementation plans and walkthroughs
  • Local model support and headless / CI execution modes
Desktop + CLI + IDE Gemini Models MCP Browser Automation
◻

OpenAI Codex

OpenAI
Dev Agent

OpenAI's cloud-based software engineering agent — accessible via the ChatGPT interface and the OpenAI API (Agents SDK). Unlike a CLI tool, Codex runs in a cloud sandbox, executing tasks in parallel on your repository. It is purpose-built for multi-file, multi-step coding tasks: writing new features, fixing bugs, migrating code, writing tests, and reviewing PRs.

  • Runs in isolated cloud sandboxes with internet-restricted access to your repo
  • Asynchronous — kick off tasks and come back when done
  • GitHub integration — reads PRs, creates commits, and opens pull requests
  • Parallel execution — multiple tasks running simultaneously
  • Powered by codex-1 model, optimised for software engineering tasks
  • Accessible via ChatGPT Pro/Enterprise or via the Agents SDK
  • Shell, file read/write, and test runner tools built in
Cloud Sandbox GitHub Integration Async Tasks codex-1 Model
✦

Anthropic Claude Code

Anthropic
Dev Agent

Anthropic's autonomous coding agent — available as a terminal CLI, VS Code/JetBrains extension, desktop app, and via the web (claude.ai/code). Unlike ChatGPT-based Codex (cloud-only), Claude Code runs locally and understands your entire codebase. Supports GitHub Actions and GitLab CI/CD integration for automated code review and issue triage.

  • Full-featured terminal CLI — edit files, run commands, manage the whole project
  • VS Code, JetBrains, and Zed extensions with inline diffs
  • Desktop app with multi-session, diff review, and scheduled tasks
  • Understands the full codebase — not just what's open
  • Git-native — stages changes, writes commit messages, opens PRs
  • MCP connections — links to Google Drive, Jira, Slack, and custom tools
  • Web mode — work on remote repos without local setup
  • Plugins — customisable instructions, skills, and lifecycle hooks
CLI + IDE + Desktop Git-Native MCP CI/CD Integration
⌖

Cursor

Anysphere
AI-Native IDE

A full AI-native code editor (forked from VS Code) where the AI agent is woven into the editing experience itself. Cursor is a model marketplace — you choose from every frontier model (GPT-5, Claude Opus, Gemini 3, Grok, Composer) per task. Trusted by over half of Fortune 500 companies and used by teams at NVIDIA, Stripe, and Cloudflare.

  • Full VS Code fork — existing settings and extensions carry over
  • Agent mode — autonomous multi-file edits with plan-then-execute flow
  • Cloud Agents — launch fleets running in parallel for hours or days
  • Model choice — every top model available per conversation
  • Plan Mode + Code Mode — structured workflow for complex features
  • Deep integrations: GitHub, GitLab, Azure DevOps, Bitbucket, Slack, Jira, Linear
  • Grok Bot — bots that sign in to your tools and complete work autonomously
  • Enterprise: SSO, privacy mode, self-hosted machines, admin dashboard
AI-Native IDE Model Marketplace Cloud Agents Enterprise
Key takeaway: Antigravity, Codex, and Claude Code are all agentic CLI/terminal-first tools; Cursor bundles a full IDE. The unique angle for each: Antigravity has Google's ecosystem and browser automation; Codex excels at async, parallel cloud tasks; Claude Code has the deepest local codebase understanding and broadest surface options; Cursor is the best choice when you want to stay in your editor and choose your model.

IBM Bob

IBM
Dev Agent

E

IBM ICA Edge

IBM Consulting
Enterprise Platform

ICA Edge is the desktop-native surface of IBM Consulting Advantage — a secure agentic AI workspace running inside a Linux microVM on your laptop. It extends ICA's capabilities to the consultant's desktop without sending sensitive data to the cloud. Unlike a chat tool, Edge plans and executes multi-step tasks with browser automation, code execution, and live editable artifacts.

  • Runs entirely inside a sandboxed Linux microVM — data never leaves your laptop
  • Agentic by default: builds dependency-aware Task Plans you approve before execution
  • Pre-built Skills for RFPs, Pricing, Research, Presentations, SOW/Risk, BPMN flows
  • Browser automation — drives SAP, ServiceNow, Salesforce as a consultant would (40% faster)
  • Live, versioned artifact library — decks, dashboards, deliverables stay editable
  • Network egress control — DNS allowlist + kill switch; no data leakage
  • Prompt injection defence — every tool result scanned before the model processes it
  • Connected Folders — Box and OneDrive mounted directly into the VM
  • Any model, including fully local — Granite, watsonx, Bedrock, Azure OpenAI
  • ROI tracking built into the task flow
Desktop-Native Local Privacy Consulting Sandboxed microVM
IBM Internal note — Edge vs. Bob: These tools complement each other and serve different personas. ICA Edge is built for IBM Consulting business users and consultants delivering client work (proposals, RFPs, decks, process flows, deliverables). IBM Bob is optimised for software development teams (writing, testing, and maintaining code). Use whichever fits the task — or both.

Microsoft Copilot

Microsoft's enterprise AI assistant — tightly integrated with Microsoft 365 and the full Microsoft cloud ecosystem.

Microsoft 365 Copilot

Microsoft
Enterprise Platform

Microsoft's AI layer across the entire Microsoft 365 suite — available in Word, Excel, PowerPoint, Outlook, OneNote, and Teams. Copilot comes in three tiers: Basic (web-grounded chat only), M365 Basic (in-app Copilot with standard access), and M365 Premium (full organisational data grounding via Microsoft Graph and Work IQ). Protected by Enterprise Data Protection (EDP) on all tiers.

  • Excel: analyse data, generate formulas, create charts and insights
  • PowerPoint: create presentations from prompts or existing content
  • Outlook: draft emails, summarise threads, coaching for clarity and tone
  • Teams: summarise and transcribe meetings, capture action items (up to 30 days)
  • Microsoft Graph grounding — personalised context from emails, calendars, files, and org charts (Premium)
  • Work IQ — intelligence layer for agents to reason over organisational data
  • Copilot Search — AI-powered universal search across all M365 apps
  • Microsoft Agents — scoped AI assistants that automate business processes
  • Cowork — carries out tasks across your M365 environment autonomously (usage-based billing)
Microsoft 365 Microsoft Graph Enterprise Data Protection Agents
Key differentiator: Microsoft Copilot's power is its depth of Microsoft 365 integration. No other tool has native access to your email history, calendar, SharePoint, and org relationships in the same way. If your team already lives in Microsoft 365, Copilot meets you there.

07 — Decision Guide

When to Use Which Tool

A practical guide based on the task at hand — not the tool's brand.

Writing, research, or Q&A

  • ChatGPT — complex reasoning, technical analysis
  • Claude — long documents, legal/policy review, polished writing
  • Gemini — research with Google Workspace context or real-time search
  • ICA Chat — consulting context, IBM IP-protected outputs

Working in Microsoft 365

  • Microsoft Copilot — the only right answer here
  • Drafting in Word, analysing in Excel, summarising in Outlook
  • Meeting transcription and action items in Teams
  • Agents that connect to SharePoint and org data

Writing & reviewing IBM code

  • IBM Bob — the only approved agentic coding tool for IBM product codebases
  • Use Ask mode to understand, Plan to design, Code to implement
  • ICA for Coding Agents — brings ICA knowledge and tools into your IDE alongside Bob

Non-IBM code / open-source / client deliveries

  • Cursor — best IDE experience, model choice, enterprise controls
  • Claude Code — deepest local codebase understanding, widest surface options
  • Antigravity — if your stack is Google Cloud / Firebase
  • Codex — async tasks against GitHub repos, no local install needed

Building IBM Consulting deliverables

  • ICA Edge — RFPs, proposals, decks, BPMN flows, SOW reviews
  • Data never leaves your laptop; runs inside a secure microVM
  • Pre-built consulting Skills make first draft fast
  • Browser automation drives SAP/ServiceNow without an API

Client data & confidential material

  • ICA Edge — data stays on-device, microVM sandboxed, all geos
  • IBM Bob — IBM-governed, no SPI/PHI processed, approved for IBM IP
  • ICA (Regional Instance) — web-based, use a client regional instance per SOW
  • Avoid: public consumer tiers of ChatGPT, Gemini, Claude without enterprise contracts

Agentic, multi-step automation

  • ICA (Agentic App Studio) — build governed multi-agent workflows at enterprise scale
  • ICA Edge — desktop-local task plans with approval-before-execute
  • Claude Cowork — business-task automation across SaaS tools
  • Cursor Cloud Agents — long-running parallel coding tasks

Process analysis & business transformation

  • ICA Process Studio — transforms business processes into agentic blueprints
  • ICA Edge — BPMN 2.0 diagrams direct to Signavio
  • ChatGPT / Claude — process documentation, gap analysis, workshop prep
